# Oyun İndirimleri

IsThereAnyDeal API kullanılarak geliştirilen bu web sitesi, en iyi oyun indirimlerini bulmanızı ve farklı mağazalardaki fiyatları karşılaştırmanızı sağlar.

## Özellikler

- Oyun arama ve bulma
- Detaylı oyun bilgileri
- Farklı mağazalardaki güncel fiyatlar
- Tarihi en düşük fiyat verileri
- Responsive tasarım

## Teknolojiler

- Next.js
- TypeScript
- TailwindCSS
- React Query
- Axios

## Kurulum

1. Projeyi klonlayın:
```bash
git clone https://github.com/kullanici/oyun-indirimleri.git
cd oyun-indirimleri
```

2. Bağımlılıkları yükleyin:
```bash
npm install
```

3. Geliştirme sunucusunu başlatın:
```bash
npm run dev
```

4. http://localhost:3000 adresini ziyaret edin.

## API

Bu proje [IsThereAnyDeal API](https://isthereanydeal.com)'sini kullanmaktadır. API kullanımı için bir API anahtarı gereklidir.
